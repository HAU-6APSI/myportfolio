# Portfolio: Paulo Miguel R. Limpin

Static site (no build step). Open `index.html` to preview locally.

## Deploy
1. Create a new GitHub repo and upload all files in this folder (keep the `assets` folder).
2. Go to vercel.com, click **Add New > Project**, import the repo.
3. Framework Preset: **Other**. Leave build command and output directory empty. Click **Deploy**.
