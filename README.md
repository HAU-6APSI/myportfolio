# Portfolio: Paulo Miguel R. Limpin

Static site (no build step). Open `index.html` to preview locally.

## Deploy
1. Upload all files in this folder to your GitHub repo (keep the `assets` folder). Replace the old files.
2. Vercel redeploys automatically after you commit. For a new project: Add New > Project, import the repo, Framework Preset: **Other**, leave build command and output directory empty, then Deploy.
